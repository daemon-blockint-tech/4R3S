# apps/auditor-api runtime + test dependencies.
#
# Deliberately narrow: this plane is a thin FastAPI/Arq wrapper around the
# existing TypeScript audit CLI, so it needs a web surface, a queue, and a way
# to test both — not an LLM client. LiteLLM is named in the ORC-1 brief but is
# not listed here yet: no code in this app calls an LLM (every model call still
# happens inside the TS graph the worker shells out to), and pinning a
# dependency with no caller would be dead weight in every install and audit.
# See docs/ORC-1-ASSUMPTIONS.md.
#
# Versions below are the ones the test suite was actually executed against, not
# chosen from a changelog. If a pin is bumped, re-run the suite rather than
# assuming compatibility.
fastapi==0.141.1
arq==0.28.0
# Ceiling is arq's, not ours: arq 0.28.0 — the latest release — declares
# `redis[hiredis]>=4.2.0,<6`. #120 bumped this to 8.1.0 and pip could not
# resolve the result at all (`ResolutionImpossible`), taking the auditor-api job
# red on main. No newer arq lifts the cap, so redis 6+ is unreachable until arq
# itself moves; dependabot.yml withholds major bumps here for that reason.
# Updates inside 5.x are fine and still flow.
redis==5.3.1
pydantic==2.13.4

# Server. Not pinned to a verified version: uvicorn is the dev entrypoint
# (`uvicorn main:app`) and is not imported by any tested code path, so no
# version of it was exercised by the suite. Pin it once it is run in CI.
uvicorn

# Originally pulled in only as FastAPI's TestClient backend (newer starlette
# versions require httpx2, no longer falling back to plain httpx — confirmed
# on PyPI: maintained by Tom Christie, httpx's original author, under
# Pydantic Services Inc., same org as the pydantic dependency above, 11
# published releases; the successor, not a typosquat of httpx). INT2 also
# uses it from app code (worker.py) to deliver webhooks, so it is no longer
# test-only.
httpx2==2.12.0

# MCP (stdio) server exposing scan/enrich as agent tools -- mcp_server.py.
# Pinned to the version this was actually built and tested against: 2.0.0
# restructured the high-level server API from the older FastMCP name/import
# path (mcp.server.fastmcp.FastMCP) to mcp.server.mcpserver.MCPServer --
# confirm the import path if this pin is ever bumped, don't assume it's
# unchanged across a major version.
mcp==2.1.1

# Tests
pytest==9.1.1
